# Midori Caption プライバシーについて

制定日：2026年9月8日  
最終改定日：2026年9月17日

本書は、MidoriTimeTVが提供するWindows用アプリケーション「Midori Caption」（以下「本アプリ」）が、どのように情報を扱うかを説明するものです。

## 1. 基本方針

本アプリは、原則として利用者の端末上で動作するよう設計されています。

MidoriTimeTVは、本アプリを通じて音声、字幕、ユーザー辞書、APIキー、利用状況などを収集するための独自サーバーを運営していません。

本アプリには、MidoriTimeTVへ音声、字幕、利用状況、端末情報などを自動送信するテレメトリー機能はありません。

外部サービスを利用する機能を有効にした場合のみ、その機能に必要な通信が発生します。

## 2. 音声認識

日本語の音声認識および音声検出は、原則として利用者の端末上で行われます。

通常のライブ字幕利用では、マイク音声をMidoriTimeTVのサーバーや翻訳APIへ送信しません。

また、通常のライブ字幕機能では、マイク音声を録音ファイルとして自動保存しません。

## 3. 字幕とOBS連携

音声認識結果や字幕は、原則として利用者の端末上で処理されます。

OBS連携では、字幕をローカル字幕サーバー経由でOBS Browser Sourceへ送ります。ローカル字幕サーバーは原則として `127.0.0.1` を使用します。

OBS Browser SourceのURLには接続用トークンが含まれる場合があるため、配信、録画、画面共有などで公開しないでください。

## 4. ローカル翻訳

ローカル翻訳を選択した場合、対象となる翻訳処理は利用者の端末上で行われ、翻訳対象テキストを外部翻訳APIへ送信しません。

初回利用時などに、必要な翻訳モデルをモデル配布元からHTTPSでダウンロードする場合があります。

モデル配布元には、IPアドレス、通信日時、要求したファイルなど、通常のインターネット通信に伴う情報が伝わる場合があります。

## 5. 外部翻訳サービス

利用者が外部翻訳サービスを有効にした場合、確定した日本語テキスト、翻訳先言語など、翻訳に必要な情報が利用者の選択したサービスへ送信されます。

対応サービスには、DeepL、Google Cloud Translation、Microsoft Azure Translator、OpenAIなどが含まれる場合があります。

選択していない翻訳サービスへ字幕本文を送信することはありません。

OpenAIを利用する場合、文脈を保つため、現在の確定発話に加えて直前の確定済み発話を最大2件送信する場合があります。

外部サービス側での情報の取扱いは、各サービス提供者の規約、プライバシーポリシー、契約内容、アカウント設定に従います。

## 6. APIキー・パスワード・OAuth情報

APIキー、OBS WebSocketパスワード、OAuthトークンなどの秘密情報は、利用者自身が取得または認可して使用します。

本アプリが保存する秘密情報は、WindowsのDPAPIなどOSの保護機能を利用し、原則として同じWindowsユーザーのみが復号できる形で端末内に保存する設計です。

MidoriTimeTVは、これらの秘密情報を収集・保管するための独自サーバーを運営していません。

設定エクスポートには、APIキー、パスワード、OAuthアクセストークン、リフレッシュトークンなどの秘密情報を含めない設計とします。

## 7. Discord連携

Discord連携は任意機能です。利用者が明示的に有効化または認可した場合のみ動作します。

Discord話者表示などの機能では、必要に応じて次のような最小限の情報を取り扱う場合があります。

- Discord User ID
- 表示名
- ボイスチャンネル参加状態
- Speaking開始・終了状態
- その他、話者表示に必要な音声状態メタデータ

本アプリは、Discord話者表示のためにDM、メッセージ本文、メッセージ履歴を取得することを目的としていません。

Discord RPC等から通話音声そのものを取得することを前提としていません。

Speaking状態は、利用者の端末上で取得したVAD/ASRの時刻情報と照合し、字幕へ話者ラベルを付けるために利用する場合があります。

Discord User ID、表示名、Speaking状態などをMidoriTimeTVが管理するサーバーへ自動送信しません。

Discord連携を無効化または解除した場合、新しいDiscordイベントの取得を停止します。

Discord側での情報の取扱いには、Discordの利用規約およびプライバシーポリシー等が適用されます。

## 8. Google Fonts

Google Fonts機能を利用した場合、Googleのサーバーへ接続することがあります。

ローカル保存を選択した場合は、選択したフォントを端末へダウンロードします。クラウド参照を選択した場合は、字幕表示中にOBS Browser Source等からGoogle Fontsへ接続する場合があります。

## 9. 端末内に保存される情報

本アプリは、設定、ユーザー辞書、翻訳用語辞書、暗号化された認証情報、診断ログ、フォントキャッシュ、WebView2データ、音声認識モデル、VADモデル、ローカル翻訳モデルなどを端末内へ保存する場合があります。

保存場所は主に `%LOCALAPPDATA%\MidoriCaption` 配下です。

一部の設定や辞書は平文で保存される場合があります。

## 10. 診断ログ

本アプリは、動作確認や障害調査のため、端末内に診断ログを保存する場合があります。

ログには、日時、処理名、エラー分類、処理時間、選択した翻訳方式、OBSのシーン名・ソース名、モデル状態などが含まれる場合があります。

APIキー、パスワード、OAuthトークン、マイク音声、字幕本文を意図的に記録しない設計とします。

診断ログはMidoriTimeTVへ自動送信されません。

## 11. 第三者への販売・提供

MidoriTimeTVは、本アプリを通じて利用者の音声、字幕、利用状況などを収集する独自サーバーを運営していないため、それらの情報を第三者へ販売しません。

利用者が外部翻訳サービス、Google Fonts、Discord、OBSなどを利用した場合は、利用者の操作と設定に基づき、利用者と各サービス提供者との間で情報の送受信が行われます。

## 12. 将来の機能

将来、動画・音声ファイル文字起こし、オンラインアカウント、クラッシュレポート自動送信、テレメトリーなど、現在存在しない情報処理機能を追加する場合は、必要に応じて本書を更新して案内します。

## 13. 本書の変更

本アプリの仕様や情報の取扱いを変更した場合、本書を更新することがあります。

重要な変更がある場合は、必要に応じてアプリ内や公開ページで案内します。
